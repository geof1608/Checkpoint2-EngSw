# Projeto Marketplace Digibuybr

Este repositório contém a documentação técnica da engenharia de sistema desenvolvida pela **SupersolucoesTI** para a startup **Digibuybr**.

## Objetivo
O projeto visa o levantamento de requisitos para gerenciar anunciantes, clientes, mercadorias e o controle logístico da plataforma de marketplace.

## Estrutura de Pastas
* **/LevantamentoRequisitos**: Contém a lista de requisitos (Rf e Rnf) e o Quadro de Análise de Valor em formato PDF.
